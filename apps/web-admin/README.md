# Maneki Admin - 管理后台

独立的 React + TypeScript 管理后台应用。

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器（默认端口 5174）
pnpm dev
```

## 构建

```bash
pnpm build
```

## 部署

构建后的文件位于 `dist/` 目录，可部署到任何静态托管服务。

## 端口配置

- 前台应用：`http://localhost:5173`
- 管理后台：`http://localhost:5174`
- 后端 API：`http://localhost:8000`
