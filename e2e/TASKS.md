## 通用测试规范

- 使用 Playwright + Chromium，通过 CDP 连接模拟真实用户行为。
- 每个测试用例需独立可运行，测试数据通过 API 或 fixtures 准备，不依赖其他测试的执行顺序。
- 测试失败时需排查根因并修复，不允许跳过或注释掉失败用例。
- 状态标记：`⬜ 未开始` → `🟡 进行中` → `✅ 已完成`
