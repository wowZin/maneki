## 1. 测试策略总览

### 1.1 测试范围

| 模块 | 服务 | 优先级 | 测试类型 |
|------|------|--------|----------|
| 用户认证 | API (Go) | P1 | 功能、安全、集成 |
| 管理员后台 | API (Go) + web-admin (React) | P1 | 功能、权限、UI |
| 通知设置 | API (Go) + web-admin (React) | P1 | 功能、集成 |
| 返佣规则 | API (Go) | P1 | 功能、计算、风控 |
| 用户等级/准确率 | API (Go) + web-admin (React) | P1 | 功能、数据 |
| 短信验证码登录 | API (Go) + web (React) | P1 | 功能、安全、性能 |
| 用户个人信息 | API (Go) + web (React) | P1 | 功能、UI |
| 灵动欢迎页 | web (React) | P2 | UI、性能、兼容 |
| 首页概览看板 | API (Go) + web (React) | P1 | 功能、数据、性能 |
| Agent 市场 | API (Go) + web (React) | P1 | 功能、权限、集成 |
| 数据源服务 | service-data (Python) | P1 | 功能、集成、数据精度 |
| 实时信号推送 | API (Go) + web SSE | P1 | 实时性、稳定性 |

### 1.2 测试环境

```
API 服务:      http://localhost:8080  (Go/Gin)
数据服务:      http://localhost:8001  (Python/FastAPI)
用户端前端:    http://localhost:5173  (React/Vite)
管理后台:      http://localhost:5175  (React/Vite)
数据库:        PostgreSQL 15 + TimescaleDB
缓存:          Redis 7
```

### 1.3 测试账号 (由测试工程师自行创建保管)

| 账号类型 | 用途 | 创建方式 |
|----------|------|----------|
| 超级管理员 | 后台管理测试 | 命令行: `go run cmd/adminctl/main.go create` |
| 普通管理员 | 权限边界测试 | 超级管理员在后台创建 |
| 普通用户 | 用户端功能测试 | 用户端注册 |
| VIP用户 | VIP功能测试 | 数据库直接修改 vip_level |

  - 返佣 = 10×10×1.0 + 20×10×1.2 = 100 + 240 = 340 元

  - 记录套利预警日志
```

#### TC-REBATE-006: 防套利 - IP频次限制
```

  - 前3次返佣正常
  后2次返佣=0，标记"疑似套利"
```

#### TC-REBATE-007: T+1 结算
```

  - 待结算记录变为"已结算"

#### TC-REBATE-008: 返佣统计 - 数据一致性
