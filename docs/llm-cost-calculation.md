## 成本临界点分析

### 什么时候本地部署更划算？

```
租用GPU固定成本: ¥1,500/月
API变动成本: ¥0.015 × 500tokens × N次

临界点计算:
¥1,500 = ¥0.0075 × N
N = 200,000次/月

结论:
- 月调用量 < 20万: API更便宜
- 月调用量 > 20万: 本地部署更便宜
```

**对应用户数**:
- 20万次 ÷ 53,240次/100人 = **约375用户**

## 优化策略

### 1. 对话合并优化

**当前**: 10个agent每10分钟各调用1次 = 240次/天
**优化**: 合并为1次批量调用

```python
# 优化后
prompt = """
```

**节省效果**:
