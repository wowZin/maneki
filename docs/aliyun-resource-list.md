## 日志配置说明

### 本地开发环境
```bash
# .env
APP_ENV=local
LOG_LEVEL=DEBUG
```
- 日志输出到控制台（彩色格式化）
- 同时写入 `logs/app_YYYY-MM-DD.log`
- 保留 14 天

### 阿里云生产环境
```bash
# 通过阿里云控制台配置环境变量
APP_ENV=aliyun
LOG_LEVEL=INFO
SLS_PROJECT=maneki-logs
SLS_LOGSTORE=maneki-api
SLS_ENDPOINT=cn-hangzhou.log.aliyuncs.com
```
- 日志输出到 stdout
- 阿里云 Logtail 自动采集到 SLS
- 支持实时查询和告警
